=======================================
SWU 샬롬하우스 관리자 앱 - 빠른 실행 방법
=======================================

빌드 오류가 발생하나요? 다음 방법을 시도해보세요:

방법 1: 자동 실행 (가장 간단!) ⭐
=====================================
1. run_with_fix.bat 파일을 더블클릭
2. 자동으로 CMake/MSBuild 오류를 처리하고 앱이 실행됩니다


방법 2: 이미 빌드된 앱 직접 실행
=====================================
1. run_direct.bat 파일을 더블클릭
2. 또는 다음 파일을 직접 실행:
   build\windows\x64\runner\Debug\swu_dormi_admin.exe


방법 3: CMake 파일 수동 수정
=====================================
1. fix_cmake.bat 실행
2. 명령 프롬프트에서 실행:
   flutter run -d windows


방법 3: Visual Studio 설치 (근본적 해결)
=====================================
1. https://visualstudio.microsoft.com/ko/downloads/
2. Visual Studio 2022 Community 다운로드
3. 설치 시 "C++를 사용한 데스크톱 개발" 선택
4. 설치 완료 후 재시작
5. flutter clean
6. flutter run -d windows
