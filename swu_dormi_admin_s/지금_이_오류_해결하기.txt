============================================
   CMake Generator 버전 충돌 오류 해결
============================================

발생한 오류:
--------------------------------------------
CMake Error: Error: generator : Visual Studio 17 2022
Does not match the generator used previously: Visual Studio 18 2026


원인:
--------------------------------------------
이전에 Visual Studio 18 (프리뷰 버전)으로 빌드한
캐시가 남아있어서 현재 Visual Studio 17과 충돌


✅ 해결 방법 (가장 간단!)
============================================

1단계: 완전재빌드.bat 실행
--------------------------------------------
프로젝트 폴더에서 다음 파일을 더블클릭:

    완전재빌드.bat

이 스크립트가 자동으로:
✓ 기존 빌드 캐시 삭제
✓ CMake 버전 수정
✓ 새로 빌드
✓ 앱 실행


2단계: 실행 확인
--------------------------------------------
빌드 완료 후 Y 입력하면 앱이 실행됩니다!


⚡ 빠른 수동 해결 (명령어)
============================================

명령 프롬프트에서:

1. 캐시 삭제:
   rd /s /q build

2. 패키지 재설치:
   flutter pub get

3. 빌드:
   flutter build windows --debug

4. 실행:
   build\windows\x64\runner\Debug\swu_dormi_admin.exe


💡 이미 빌드된 앱이 있다면
============================================

현재 build 폴더에 실행 파일이 있을 수 있습니다.
확인 방법:

1. 앱실행.bat 더블클릭
2. 또는 run_direct.bat 더블클릭

실행되면 재빌드 불필요!

============================================

- TROUBLESHOOTING.md - 상세한 문제 해결 가이드


지금 바로 "완전재빌드.bat"을 실행하세요! 🚀
