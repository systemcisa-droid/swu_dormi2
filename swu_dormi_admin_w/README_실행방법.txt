============================================
  SWU 샬롬하우스 관리자 앱 실행 방법
============================================

✅ 좋은 소식: 앱이 이미 빌드되었습니다!


🚀 앱 실행하기 (3가지 방법)
============================================

방법 1: 가장 간단 (더블클릭!)
--------------------------------------------
앱실행.bat


방법 2: 직접 실행
--------------------------------------------
build\windows\x64\runner\Debug\swu_dormi_admin.exe


방법 3: 자동 스크립트
--------------------------------------------
run_direct.bat


⚠️ MSBuild 오류에 대해
============================================
빌드 시 다음과 같은 오류가 표시되더라도 걱정하지 마세요:

  "error MSB3073: 명령이 종료되었습니다(코드: 1)"
  "Build process failed"

이것은 INSTALL 단계의 오류일 뿐입니다.
실행 파일(swu_dormi_admin.exe)은 정상적으로 생성되었습니다!


🔧 개발을 계속하려면
============================================

1. Flutter PATH 설정
   - Flutter_PATH_설정_가이드.md 참조

2. Firebase 설정
   - QUICKSTART.md 참조

3. 코드 수정 후 재빌드
   - run_with_fix.bat 실행


📚 더 많은 정보
============================================
- 시작하기.md - 빠른 시작 가이드
- TROUBLESHOOTING.md - 문제 해결
- SETUP.md - 상세 설정 가이드


💡 Windows Defender 경고가 뜨면?
============================================
"추가 정보" 클릭 → "실행" 선택


지금 바로 "앱실행.bat"을 실행해보세요! 🎉
