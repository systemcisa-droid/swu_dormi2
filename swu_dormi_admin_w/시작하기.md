## ⚠️ 발생한 오류들에 대한 설명

### 1. CMake 버전 오류 ✅ 해결됨
```
Compatibility with CMake < 3.5 has been removed
```
**해결:** Firebase SDK의 CMake 파일을 3.5 버전으로 수정했습니다.

### 2. MSBuild INSTALL 오류 ✅ 무시해도 됨
```
error MSB3073: 명령이 종료되었습니다(코드: 1)
Build process failed
```
**중요:** 이 오류는 무시해도 됩니다!
- 실행 파일(`swu_dormi_admin.exe`)은 이미 정상적으로 생성되었습니다
- INSTALL 단계의 오류일 뿐, 앱 실행에는 전혀 문제가 없습니다
- 실제로 앱이 정상 작동합니다

## 💡 자주 묻는 질문

### Q: 앱이 실행되지 않아요
A: Windows Defender가 차단할 수 있습니다. "추가 정보" → "실행"을 클릭하세요.

### Q: 로그인이 안 돼요
A: Firebase 설정과 관리자 계정 생성이 필요합니다. QUICKSTART.md를 참조하세요.

### Q: 빌드 오류가 계속 발생해요
A: 걱정하지 마세요! 실행 파일은 이미 생성되어 있습니다. `run_direct.bat`을 실행하세요.

### Q: Visual Studio를 설치해야 하나요?
A: 이미 빌드가 완료되었다면 필수는 아닙니다. 하지만 개발을 계속하려면 설치를 권장합니다.
